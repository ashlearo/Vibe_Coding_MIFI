# Вайб-кодинг: домашние задания

Репозиторий с домашними заданиями по курсу **«Вайб-кодинг: разработка приложений с помощью AI»**.

## 📋 О репозитории

Здесь собраны практические работы, выполненные в рамках курса. Каждое задание — отдельный проект в своей папке (или отдельный файл, если задание небольшое). По мере прохождения курса репозиторий пополняется новыми работами.

## 📁 Структура репозитория

```
.
├── README.md              # Этот файл — общее описание репозитория
├── .gitignore             # Исключения для Git (node_modules, ключи, HTML и т.д.)
├── homework-1.js          # ДЗ 1 — Консольное меню
└── homework-1-review.md   # ДЗ 1 — учебный разбор кода
```

> По мере добавления новых заданий структура будет расширяться. Актуальный список — в разделе «Задания» ниже.

## 📚 Задания

### ДЗ 1. Консольное меню

Консольное приложение на Node.js с интерактивным меню из трёх задач: билетная касса, доставка заказа, лестница.

**Запуск:**
```bash
node homework-1.js
```

**Что демонстрирует:** `readline/promises`, `switch`, `while` (без деления), `for` с `continue` и `break`, разделение функций-калькуляторов и функций-принтеров.

**Материалы:**
- `homework-1.js` — решение.
- `homework-1-review.md` — учебный разбор: цитаты задания, объяснение каждой функции, таблица крайних случаев.

_Список будет пополняться по мере выполнения следующих заданий._

## 🚀 Общие требования к запуску

Для заданий на Node.js требуется установленный [Node.js](https://nodejs.org/) (версия 18+). Для каждого задания способ запуска указан в его разделе.

## 🛠 Использование AI

При выполнении заданий AI использовался для генерации и проверки логики, разбора крайних случаев и подготовки учебных разборов. Итоговый код проверен и объяснён автором. Для каждого задания конкретное использование AI описано в соответствующем разборе (если он есть).

# Вайб-кодинг: домашние задания

Репозиторий с домашними заданиями по курсу **«Вайб-кодинг: разработка приложений с помощью AI»**.

## 📋 О репозитории

Здесь собраны практические работы, выполненные в рамках курса. Каждое задание — отдельная папка с решением и учебным разбором. По мере прохождения курса репозиторий пополняется новыми работами.

## 📁 Структура репозитория

```text
.
├── README.md                   # Этот файл — общее описание репозитория
├── .gitignore                  # Правила Git: пушим только скрипты, HTML и md
├── DZ_1/                       # ДЗ 1 — Консольное меню (Node.js)
│   ├── Readme.md               # Описание задания и структуры
│   ├── homework-1.js           # Решение
│   ├── homework-1.html         # HTML-версия решения
│   └── homework-1-review.md    # Учебный разбор кода
└── DZ_2/                       # ДЗ 2 — Конструктор посещения события (браузер)
    ├── README.md               # Описание задания и структуры
    ├── src/                    # Исходный код решения
    │   ├── index.html          # HTML-каркас страницы
    │   ├── style.css           # Стили
    │   └── app.js              # Логика приложения
    ├── homework-2-review.md    # Учебный разбор кода
    └── homework-2-review.html  # Разбор кода (HTML-версия)
```

## 📚 Задания

### ДЗ 1. Консольное меню

Консольное приложение на Node.js с интерактивным меню из трёх задач: билетная касса, доставка заказа, лестница.

**Запуск:**
```bash
node DZ_1/homework-1.js
```

**Подробности:** [`DZ_1/Readme.md`](DZ_1/Readme.md)

### ДЗ 2. Конструктор посещения события

Одноколоночная интерактивная карточка события с программой и калькулятором дополнительных услуг. Демонстрирует JSON, DOM, обработку событий и работу с массивами.

**Запуск:**
```text
Открыть DZ_2/src/index.html двойным кликом в любом современном браузере
```

**Подробности:** [`DZ_2/README.md`](DZ_2/README.md)

## 🚀 Общие требования к запуску

Для заданий на Node.js требуется установленный [Node.js](https://nodejs.org/) (версия 18+). Для браузерных заданий сервер не требуется.

## 🛠 Использование AI

При выполнении заданий AI использовался для генерации и проверки логики, разбора крайних случаев и подготовки учебных разборов. Итоговый код проверен и объяснён автором. Для каждого задания конкретное использование AI описано в соответствующем разборе (если он есть).

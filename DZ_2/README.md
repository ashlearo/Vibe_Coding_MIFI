# Вайб-кодинг: ДЗ 2. Конструктор посещения события

Репозиторий с решением домашнего задания №2 по курсу **«Вайб-кодинг: разработка приложений с помощью AI»**.

## 📋 О проекте

Одноколоночная интерактивная карточка события с программой и калькулятором дополнительных услуг. Проект демонстрирует интеграцию JSON-данных, манипуляции с DOM, обработку событий и работу с массивами в JavaScript, а также базовую верстку без использования современных фреймворков и Flexbox/Grid.

## 📁 Структура проекта

```text
.
├── README.md                 # Этот файл — описание задания
├── src/                      # Исходный код решения
│   ├── index.html            # HTML-каркас страницы (структура)
│   ├── style.css             # Стили (оформление)
│   └── app.js                # Логика работы приложения (скрипт)
├── homework-2-review.md      # Учебный разбор кода (Markdown)
└── homework-2-review.html    # Учебный разбор кода (HTML-версия для чтения)
```

## 🚀 Как запустить

Сервер не требуется. Приложение работает локально прямо из файловой системы.

1. Скачайте папку с проектом.
2. Откройте файл `src/index.html` двойным кликом в любом современном браузере (Chrome, Firefox, Safari, Edge).

## 🛠 Что демонстрирует код

- **JSON и обработка ошибок:** Безопасный парсинг строки `sourceJson` через `JSON.parse()` внутри `try...catch`.
- **Методы массивов:** Использование `filter` (отбор), `map` (трансформация с деструктуризацией и `trim()`) и `reduce` (подсчёт суммы).
- **DOM и События:** Поиск элементов через `document.querySelector('#id')`, работа со свойством `hidden`, обработка кликов (`click`) и отправки формы (`submit`) с `event.preventDefault()`.
- **Строгий CSS:** Верстка с использованием только базовых свойств (margin, padding, border, цвет), без Flexbox, Grid и псевдоклассов (в соответствии с условиями задания).

## 📚 Материалы

- `src/index.html`, `src/style.css`, `src/app.js` — исходный код решения.
- `homework-2-review.md` — подробный учебный разбор: цитаты из ТЗ, объяснение каждой функции, чек-лист и разбор крайних случаев.
- `homework-2-review.html` — тот же разбор в виде красиво оформленной веб-страницы (для удобства чтения).
